FORTH GRAPH ∞ — HOW TO USE

Each node is a small program that draws a generative visualization. You breed nodes together to mix their programs and evolve new visuals. The more you breed, the further the visuals drift from the originals.

Selecting nodes

Click any node to select it as P1 (orange). Click a second node to select it as P2 (blue). Click a selected node again to deselect it. Drag nodes freely to rearrange.

Buttons

BREEDCombine P1 and P2 into a child node. The child's program is a splice of both parents, with a small random tweak. The child becomes P1 automatically.
ANIMATEBring the selected node to life as a real-time animation. The animated version starts from the same visual state as the static snapshot.
GENERATEAdd one new random node — either a mutated seed program or a crossover of two seeds. Good for fresh starting material.
EXPORTDownload the selected node. Static nodes save as PNG. Animated nodes record 3 seconds as a WebM video.
AI INJECTUse Claude AI to write a brand-new Forth program based on the theme you typed. Requires an API key (see below).
AUTOToggle automatic AI injection on a timer (30s / 60s / 120s / off). Keeps adding new nodes without you clicking.
KEYSet your Anthropic API key. Required for AI INJECT and AUTO. Saved in your browser's local storage.
RESETClear everything and start fresh with 6 new random seed nodes.
Delete keyRemove the currently selected node (and cancel its animation if live).

Theme / vibe input

Type a word or phrase (e.g. ocean, fragmentation, warm chaos) before clicking AI INJECT. Claude will write a Forth program that evokes that feeling. Press Enter as a shortcut.

About breeding

Breeding is inherently random — the splice point is chosen at random, and a mutation is applied on top. Sometimes the child looks exactly like one parent. Sometimes it looks blank or broken. That's a happy accident. Don't delete it — breed it with something else, or move on to other nodes and come back. Unexpected results are part of the process.

Anthropic API key

Required only for AI INJECT and AUTO. Get one at console.anthropic.com. It is stored locally in your browser and never sent anywhere except Anthropic's API.
